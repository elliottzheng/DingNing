# 数据模型

SQLite 单文件多库架构：

```
data/
├── system.db          # 部署级：用户、会话、邀请码、部署配置
└── users/<用户名>.db   # 每位老师一个独立业务库，互不可见
```

所有查询走 `db.conn()`（按登录上下文路由到对应用户库的短连接，行工厂 sqlite3.Row）。
结构迁移统一在 `db.init_db_file()`（幂等，逐库容错）。

## system.db

| 表/键 | 用途 |
|---|---|
| users | 用户：username / pw_hash (PBKDF2) / is_admin / created_at |
| sessions | 会话：token / username / expires_at（90 天） |
| config.invite_code | 注册邀请码 |

## users/<用户名>.db

### lessons（课表）

| 列 | 说明 |
|---|---|
| weekday / section / start_time / end_time | 周期课的星期、节次、起止 |
| class_name / subject / location | 班级（存"20班"原始格式）、科目、地点 |
| effective_from | 生效日期；导入新版本按此版本化，互不覆盖 |
| **date** | **NULL = 每周循环课；有值 = 仅该日期的单次课（调课/补课）** |
| note | 单次课的调课说明（块内括号渲染） |

调课模型：**调课 = 停课记录（lesson_cancels）+ 单次课行（date 有值）**。
原课带灰色"已调走"标记，新课蓝色显示，来源说明在块内括号。

### lesson_cancels（停课/调出记录）

| 列 | 说明 |
|---|---|
| date / weekday / section | 被调走课的原时段 |
| note | 去向（如"调至 2026-10-30 下午2"），日视图调课摘要引用 |

### events（一次性日程）

| 列 | 说明 |
|---|---|
| date / start_time / end_time / title / location / note | 基本字段 |
| source | user（可编辑）/ calendar（校历导入，不可删） |
| kind | event / exam / holiday / festival / week_note |
| suspends | 1 = 该日停课（运动会/大考等自动识别） |
| remind_min | 开始前提前提醒分钟（NULL = 不提醒） |
| embed | 语义搜索向量（BAAI/bge-large-zh） |

### todos（待办）

| 列 | 说明 |
|---|---|
| title / due / priority / note / done | 基本字段 |
| remind_min | 距截止提前提醒分钟 |

### reminders_sent（已发提醒防重）

rkey 唯一键：`类型:id:提前量:时间`。扫描器发过即记，重启不重复。

## config 键（部分）

| 键 | 用途 |
|---|---|
| lesson_times | 作息时间表（节次 → 起止），导入/设置页维护 |
| lesson_remind_min | 全局上课提醒分钟（留空 = 不提醒） |
| schedule_overrides | 调休：`{日期: 按周几}`（如周日按周二上课） |
| my_subjects / my_classes | 我的科目别名与班级（Excel 导入识别用） |
| subject_groups | 科目组结构化配置：`[{name, aliases}]`（多科目别名归一） |
| lesson_subject | 科目统一显示名（旧版兼容） |
| wxpusher_uid | 用户级：WxPusher 订阅 UID |
| ai_api_key / ai_model | DeepSeek（自然语言解析） |
| siliconflow_key | SiliconFlow（语义搜索向量） |
| pushplus_token / wxpusher_app_token | 推送渠道凭据 |
| last_digest_date | 已推送摘要日期标记（补发判断） |

## 设计约定

1. **调课不造日程**：调课是课表域操作（停课 + 单次课），不进 events
2. **单次课不受节次停课影响**：停课键只作用于循环课
3. **科目别名按清单顺序归一**：科目名在前、别名在后，别名 → 最近的包含它的主名
4. **停课日（suspends）**：当天全部循环课置灰，单次课不受影响
5. **迁移幂等**：init_db_file 可重复执行，逐库容错（单库失败不影响其他）
