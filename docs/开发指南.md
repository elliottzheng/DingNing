# 开发指南

## 代码地图

```
server.py            FastAPI 组装：中间件（会话+安全头+CSP）、路由挂载、静态页、启动任务
db.py                SQLite 多库架构：system.db（部署级）+ users/<用户名>.db（业务级）
                     init_db_file 幂等迁移（逐库容错）；conn() 按登录上下文路由
logic.py             日/周视图组装、调课模型（循环课+单次课）、周次计算、待办排序
common.py            会话校验、登录限流、密码哈希、lesson_at/class_sections_on 等共享查询
routes/              APIRouter 按域拆分：schedule / events / todos / admin / chat
agent.py             自然语言智能体：plan→validate→apply 原子执行 + 撤销
nparser.py           中文自然语言 → 日程/待办 结构化解析（规则，离线）
ai_parse.py          DeepSeek 自然语言解析（可选，失败回退 nparser）
systemone.py         SiliconFlow SystemOne（已从运行链路移除，保留测试端点）
excel_import.py      课表/校历 Excel 与明文导入（版本化、格式自适应、科目归一）
eventsearch.py       事件语义搜索（bge 向量 + 余弦），离线回退关键词
wxpusher.py          WxPusher APP 推送通道
wxpusher_qr.py       WxPusher 扫码订阅（二维码 + 时间窗匹配 UID）
mailer.py            定时任务：每晚摘要、分钟级提醒扫描、微信指令轮询、补发看门狗
accounts.py          用户/会话/密码（系统库）
models.py            Pydantic 请求模型
static/              前端（原生 ES Modules，无构建）
tests/               pytest 套件（临时数据库隔离，不碰真实数据）
```

## 加功能的标准流程

1. models.py 加请求模型（如需）
2. routes/ 加端点或 agent.py 加工具
3. tests/ 加测试（临时库隔离）
4. 前端改动同步 static/
5. `node --check`（JS）+ ESM 编译测试 + pytest 全绿
6. **改后端必须重启服务**；前端刷新即可

## 测试

```bash
python -m pytest -q
```

全部测试使用临时数据库（WORKBENCH_DB 环境变量隔离），永不触碰真实数据。

## JS 校验三步（踩过坑的流程）

1. `node --check file.js` 初筛
2. ESM 编译测试：临时目录 + `package.json {"type":"module"}` + `node --check`（权威）
3. 浏览器逐区截图亲眼确认（禁止只查隐藏 DOM 元素）

## 已知陷阱

- JS 改完必须过 ESM 编译测试（`node --check` 假阴性踩过）
- `forEach` 回调里不能 `continue`（用 `return`）
- Python ast.parse 不能检查 JS 文件（会误报 中文括号 语法错误）
- 改后端（*.py）必须重启服务；只改前端刷新即可
- day_items 的 `type` 字段值是 `lesson/event/calendar`，没有 `user`（week.js 曾因此全绿渲染踩坑）
- 多库迁移要逐库容错（单库被锁不能中断其他库迁移）
