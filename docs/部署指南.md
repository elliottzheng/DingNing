# 部署指南

叮咛是单机多用户应用：一台机器常驻运行，组内老师各自账号登录使用。

## 环境要求

- Python 3.10+
- Windows / macOS / Linux 均可（Windows 下建议以 pythonw 常驻）

## 安装

```bash
git clone https://github.com/<you>/dingning.git
cd dingning
pip install -r requirements.txt
```

## 启动

```bash
uvicorn server:app --host 127.0.0.1 --port 8321
```

- 首次启动自动建库（`data/` 目录）
- 浏览器打开 `http://127.0.0.1:8321`，注册**首个账号**（自动成为管理员）
- 后续教师：管理员在「设置 → 安全 → 用户管理」查邀请码，新教师注册时填入

## 数据与备份

- 所有业务数据在各用户的 SQLite 文件：`data/users/<用户名>.db`
- 系统级数据（账号/会话/邀请码）：`data/system.db`
- **备份 = 复制 `data/` 目录**；`logs/` 为运行日志可随时删

## 推送配置（可选）

叮咛支持两个推送渠道，可任选、可并用（WxPusher 优先）：

### WxPusher（APP 推送，推荐）

1. 管理员在 [wxpusher.zjiecode.com](https://wxpusher.zjiecode.com) 创建应用，得到 `appToken`
2. 管理员：设置 → 推送 → WxPusher → 填入 appToken（仅管理员可见此字段）
3. 每位老师：装 WxPusher APP → 点「扫码订阅」扫页内二维码 → UID 自动填入 → 保存
4. 点「测试 WxPusher」验证收到

### PushPlus（微信推送，兜底）

1. 每位老师在 [pushplus.plus](https://pushplus.plus) 微信扫码登录，复制自己的 token
2. 设置 → 推送 → PushPlus → 填入 token → 保存
3. 点「测试 PushPlus」验证

> WxPusher 配置齐全时优先走 APP 推送；失败或未配置自动回退 PushPlus。

## AI 配置（可选，全部可降级）

- **DeepSeek**（自然语言理解）：[platform.deepseek.com](https://platform.deepseek.com) 创建 key → 设置 → SiliconFlow 区旁的 AI 配置 → 填入。未配置时系统用规则解析兜底
- **SiliconFlow**（语义搜索向量）：注册后创建 key → 设置 → SiliconFlow 区填入。未配置时搜索退化为关键词匹配

## 局域网 / 公网访问

- 局域网：启动时 `--host 0.0.0.0`，老师用 `http://<电脑IP>:8321` 访问；Windows 防火墙放行 8321 端口
- 公网：务必套 HTTPS 反向代理（caddy/nginx），并强密码；系统自带登录限流与会话过期

## 开机自启（Windows 示例）

```vbs
' 启动工作台.vbs —— 放入 shell:startup
Set sh = CreateObject("WScript.Shell")
sh.CurrentDirectory = "D:\dingning"
sh.Run """D:\dingning\venv\Scripts\pythonw.exe"" ""D:\dingning\server.py""", 0, False
```

或用任务计划程序在登录时运行 uvicorn 命令。

## 常见运维

| 现象 | 处理 |
|---|---|
| 端口被占 | `--port` 换端口，或排查占用进程 |
| 改了后端不生效 | 重启服务（前端改动刷新即可） |
| 数据库损坏 | 用 `data/` 备份恢复；SQLite 本身极稳 |
| 忘记密码 | 管理员可删除该用户重建，或直接改 system.db 的 users 表 |

## 安全说明

- 密码 PBKDF2-SHA256 20 万次迭代，不存明文
- 连续 5 次登录失败锁定 15 分钟（内存计数）
- 会话 90 天过期，改密/退出即吊销全部会话
- 安全响应头：CSP / nosniff / X-Frame-Options DENY / Referrer-Policy no-referrer
