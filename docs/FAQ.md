# FAQ

**Q：数据存在哪里？会上传吗？**
A：全部数据在本机 `data/` 目录的 SQLite 文件里。除你主动配置的推送（WxPusher/PushPlus）和可选 AI 服务（DeepSeek/SiliconFlow）外，没有任何数据离开本机。

**Q：忘记密码怎么办？**
A：管理员可在用户管理删除该账号重建（数据随之清空，慎用）；或直接编辑 `data/system.db` 的 users 表重置。

**Q：支持几个老师同时用？**
A：多用户架构，各老师独立数据库互不可见。单机部署实测几十人无压力。

**Q：AI 相关的服务要收费吗？不配置行不行？**
A：完全可选。DeepSeek（自然语言解析）和 SiliconFlow（语义搜索向量）按官方价格收费且都很便宜；不配置时系统自动降级为规则解析和关键词搜索，**所有核心功能不受影响**。

**Q：调课怎么操作？**
A：周视图里点要调的课 → 调课 → 选目标日期和时段。系统自动：原课标"已调走"（顶部摘要可见去向）+ 新日期生成蓝色单次课。支持 A↔B 互换。

**Q：换了学期/学年课表怎么办？**
A：设置 → 课表导入 → 新课表设未来生效日。到日自动切换，旧课表保留可回溯。

**Q：提醒推到哪里？**
A：WxPusher APP（推荐，秒级）或 PushPlus 微信。设置 → 推送 → 各渠道测试按钮验证。

**Q：为什么叫叮咛？**
A：叮咛 = 反复地嘱咐、提醒——这正是它每天为你做的事。也与上课铃声谐音。
