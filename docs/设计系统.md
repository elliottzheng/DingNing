# 设计系统（叮咛）

> 全站 UI 的唯一权威来源。改样式前先读本文；新增控件必须走这里的组件通道，禁止散落硬编码。

## 一、设计令牌（:root）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` #f5f6f8 | 页面底 | body 背景 |
| `--card` #ffffff | 卡片底 | 卡片/弹层/顶栏 |
| `--field` #f8f9fc | 输入底 | 所有输入控件背景 |
| `--text` / `--muted` | 文字/次要 | |
| `--line` / `--line-soft` | 描边两级 | |
| `--accent` #2e5ce6 / `--accent-deep` / `--accent-weak` | 主色三件 | 主按钮/链接/选中底 |
| `--danger` 系 | 危险 | 删除/考试/超期 |
| `--ok` | 成功 | 完成/用户日程文字 |
| `--radius` 12px / `--radius-s` 8px | 圆角 | 全站只用这两档 |
| `--shadow` | 卡片投影 | |

### 类目色板（语义色，一组 = 底/描边/文字）

| 组 | 令牌 | 语义 |
|---|---|---|
| 琥珀 | `--amber-bg/line/text` | 假期、节日、临期、已调课徽标 |
| 绿 | `--green-bg/line/text` | 用户日程 |
| 紫 | `--purple-bg/line/text` | 待办 |
| 红 | `--red-bg/line/text` | 考试、错误 |
| 信息蓝 | `--info-line` | 校历标签、表单描边 |
| 课程蓝 | `--blue-bg/line/text` | 课程块（今日/本周同色） |

**规则**：语义色只允许引用令牌，禁止新写 hex。加新语义 = 加一组三令牌。

## 二、按钮

| 变体 | 写法 | 用途 |
|---|---|---|
| 二级（默认） | `<button>`（无类） | 一般动作、测试、追加行 |
| 主操作 | `class="primary"` | 每个分区/表单的**唯一**主保存/导入按钮 |
| 导航弱化 | `class="ghost"` | 顶栏、行内添加 |
| 危险 | `class="danger"` | 删除账号、退出登录 |
| 行内删除 | `class="del"` | 条目 ×，轻量无框 |

- 全站按钮基座自动继承（`button {}`），无需手写圆角/内边距
- 一个分区**只有一个** `primary`；辅助动作一律默认二级
- 高度 32px（移动端 38px+），移动端 `white-space: nowrap`

## 三、输入

- 全站基座自动继承（`input/select/textarea {}`）：描边 + `--field` 底 + 聚焦主色描边 + 3px 柔光
- 覆盖场景（都是**故意的**，别"修"）：`#q-input`/`#quick-input` 顶栏紧凑、`.time-row/.subj-row` 行内组合、`.auth-card` 登录页、移动端 16px 防缩放
- 明文多值一律**顿号/逗号分隔的自然输入**，前端解析（参考 `_parseList`），禁止让用户写 JSON

## 四、分段选择器（互斥模式）

```html
<div class="seg">
  <label><input type="radio" name="xx" value="a" checked>选项A</label>
  <label><input type="radio" name="xx" value="b">选项B</label>
</div>
```
用例：明文课表的覆盖/追加。选中项 = 主色胶囊（`:has(input:checked)`）。

## 五、卡片与弹层

- 卡片：`.card`（主区）、`.cfg-sec`（设置分区）、`.wkm-day`（周移动端）——同描边圆角体系
- 弹层：`.modal-card`（桌面 540px / 移动全屏）+ `.modal-head` sticky + `.modal-body`
- 分区导航：`.cfg-nav` 吸顶 + `.cfg-chip`（active 主色）
- 打开弹层**必须**：先复位 `scrollTop = 0`，再执行定位跳转（顺序不能反）

## 六、徽标（胶囊形，11px 加粗）

`.offtag`（琥珀，停课原因）/ `.caltag`（考试红/活动蓝）/ `.live`（进行中红）/ `.weekbadge`

## 七、JS 组件通道

- 科目组行：`subjRow(name, aliases)` + `renderSubjectGroups(groups, flat)`
- 设置分区导航：`buildCfgNav()` / `focusSec(id)`
- 跳转约定：`openSettings()` 不传参 = 顶部；`openSettings(true, "sec-id")` = 定位。**绑定必须是箭头函数**，直接绑会把 click 事件误传为参数（踩过）
- 解析自然输入：`_parseList(v, stripBan)`（顿号/逗号/空格 → 数组）

## 八、校验流程（改前端必做）

1. `node --check` 仅初筛；**权威校验 = ESM 编译测试**（data:URL 动态 import，见
   `node -e "import('data:text/javascript;base64,'+...)"`），或临时目录 + `package.json {"type":"module"}` + `node --check`
2. 逐区截图亲眼确认（headless 浏览器），禁止只查隐藏 DOM 元素
3. 129+ pytest 全绿后提交
