使用说明

三步开始

  1. 导入课表 —— 设置 → 课表导入：上传学校发的 Excel（按提示填「我的科目 / 我教的班级」），或直接粘贴一行一节的明文课表
  2. 对齐作息 —— 设置 → 作息时间表：每节课的时间范围，可增删节次
  3. 开启推送 —— 设置 → 推送：填入你的 PushPlus token，每晚自动推送明日安排到微信

    设置

    导入课表

    方式一：粘贴明文课表（推荐，最快）

    一行一节课：星期 节次 班级 [科目课]（顺序随意，可多个班；# 开头为注释）。科目可写别名（如「文」，自动归一到你的科目名）。格式细则见《课表文本格式说明》。

    生效日

    生效日 = 这份课表从哪天开始执行（之前的日期仍显示旧课表）。覆盖 = 整份重导该生效日；追加 = 保留已有课，补加新课/单节常驻课，同班同节次自动更新。

    方式二：上传 Excel 文件

    支持学校的年级大课表（行=班级、列=星期×节次、格=科目）与个人课表（行=节次、格=班级名）。文件名含「教学安排/校历」按校历导入。

    方式三的识别配置：我的科目与班级

    给方式一/二做科目归一与班级过滤：格子里的简称（如「文」）会归一到下面的科目名。教多门课就加多行。

    作息时间表

    调休与补班

    某天按另一个星期的课表上课（如周六补班按周一、调休按周二）。当天日视图会出现调休横幅，推送与周视图同步跟随。

    明文校历导入

    一行一件事：日期 事项名称（自动识别 假期/考试/活动；日期区间自动按天展开；行尾可用 [假期] [考试] [活动] 显式标注）。整份导入会替换现有校历；有错全不导。

    事件名含「运会 / 期中 / 期末 / 月考」默认当天停课；其他事项可加行尾标注 [停课]。停课日课程自动标记、课堂归属跳过，无需逐节登记。

    推送

    每晚这个时间把明日安排（课表 + 待办）推送到你的接收渠道。下方配置了 WxPusher 就走 APP，否则走 PushPlus 微信。
